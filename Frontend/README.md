# AI Knowledge Inbox - Frontend

React 19 + TypeScript + Tailwind CSS v4 single-page application for note ingestion, URL scraping, knowledge inbox list, and RAG search.

> For full architectural documentation and API specification, see the root [README.md](../README.md).

---

## 🚀 How to Run the Frontend

From the `Frontend/` directory:

```powershell
# 1. Install dependencies (if not already installed)
npm install

# 2. Start the Vite development server
npm run dev
```

* **Frontend Web Application**: http://localhost:5173
